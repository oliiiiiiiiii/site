## Classes of Computing Applications

|  | Desktop Computer | Server | Embedded Computers |
| - | - | - | - |
|  | 由個人使用，常包含圖形顯示、鍵盤、滑鼠 | used for running larger programs for multiple users and typically accessed only via network | 在一個 device 裡面嵌入的 computer（e.g. microcontroller for cars、phones、⋯⋯） |
| 設計重點 | - performance & cost <br /> - meeting performance requirement for a board range of applications | - dependability & scalability <br /> throughput（單位時間完成多少工作） > latency（一個工作花多少時間） | - minimize power & cost <br /> - dependability |

## PostPC Era
![截圖 2026-09-14 13.04.00](https://hackmd.io/_uploads/B1aBebHYzg.png)
- Personal Mobile Device（PMD）
    - battery operated
    - connects to the internet
    - hundreds of dollars
    - smart phones, tablets, electronic glasses
- Cloud Computing
    - warehouse scale computers（WSC）
    - software as a service（SaaS）
    - portion of software run on a PMD and a portion run un the Cloud
    - Amazon and Google
